# UI Style Spec (iOS-ish)

## 设计原则
- 浅色背景 + 轻微渐变光晕：提升层次感但不过度花哨。
- 卡片化容器：Expander/侧边栏区块统一圆角、细边框、柔和阴影。
- 一致的圆角：按钮/输入框统一 12~14px，按钮更大圆角。
- 强调信息层级：正文色更深、说明/注释更浅。

## 颜色建议
- 背景：`#F5F6FA`
- 卡片：`rgba(255,255,255,0.86)`
- 边框：`rgba(15,23,42,0.10)`
- 主色：`#0A84FF`（可用渐变辅色 `#7C3AED`）
- 正文：`rgba(15,23,42,0.92)`
- 次级文字：`rgba(15,23,42,0.64)`

## 组件规则
- Sidebar：玻璃拟态（半透明 + blur）+ 右侧细边框。
- Expander：卡片背景 + 阴影，内容间距适中。
- Tabs：胶囊式圆角。

## 实现方式
- 在 `src/ui/app.py` 使用 `st.markdown(..., unsafe_allow_html=True)` 注入全局 CSS。
