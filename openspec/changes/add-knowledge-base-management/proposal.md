# Proposal: Add Knowledge Base Management

## Summary
重构系统架构，仿照RAGFlow实现多知识库管理功能，支持用户创建独立知识库、增量文档上传、知识库隔离聊天。

## Motivation
当前系统每上传一个文档都是独立运行，无法：
1. 在同一领域下增量积累知识
2. 隔离不同领域的知识（如紫微斗数 vs 八字命理）
3. 让用户选择特定知识库进行问答

## What Changes

### 1. 知识库管理层
- 新增 `KnowledgeBase` 数据模型
- 知识库CRUD操作（创建、列表、删除）
- 知识库配置（名称、描述、提取配置profile）

### 2. 增量知识积累
- 同一知识库下多文档共享：
  - 向量库collection
  - 知识图谱（实体+关系）
- 新文档增量扩充现有图谱，不重建

### 3. UI重构
- 左侧边栏：知识库选择器
- 工作流：先选库 → 上传文档 → 提取 → 入库
- Agent聊天：必须先选择知识库

### 4. 默认配置调整
- 默认LLM改为 gpt-5.2-high（Sonetto）

## Impact
- **Breaking Change**: 现有缓存结构需迁移
- **UI变更**: 侧边栏布局重构
- **数据模型**: 新增知识库层

## Rollout Plan
1. 阶段1：后端知识库管理模块
2. 阶段2：UI重构
3. 阶段3：数据迁移工具（可选）
