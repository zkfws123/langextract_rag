# UI 文档列表规范（Delta）

## ADDED Requirements

### Requirement: 文档选择联动
系统 SHALL 在用户选择文档时，自动更新当前文档状态并联动刷新右侧所有标签页的数据显示。

#### Scenario: 点击 Expander 选中文档
- **WHEN** 用户点击展开某个文档的 expander
- **THEN** 系统将该文档设置为当前选中文档（`session.current_doc_id`）
- **AND** 右侧所有标签页（OCR、预览、提取结果、图谱）自动显示该文档的数据
- **AND** 该文档的 expander 保持展开状态

#### Scenario: 点击查看按钮
- **WHEN** 用户点击文档的"查看"按钮
- **THEN** 系统将该文档设置为当前选中文档
- **AND** 自动切换到"OCR 对比"标签页（默认查看页）
- **AND** 加载并显示该文档的所有可用资料

#### Scenario: 多文档快速切换
- **GIVEN** 知识库中有多个文档
- **WHEN** 用户依次点击不同文档的"查看"按钮
- **THEN** 每次点击后，右侧标签页立即刷新显示对应文档的数据
- **AND** 之前选中的文档 expander 自动收起
- **AND** 新选中的文档 expander 自动展开

### Requirement: 文档选中状态视觉反馈
系统 SHALL 为当前选中的文档提供明显的视觉标识，帮助用户快速识别当前正在查看的文档。

#### Scenario: 显示选中状态图标
- **WHEN** 某个文档被选中为当前文档
- **THEN** 该文档的 expander 标题前显示选中状态图标（如 "📌" 或 "✓"）
- **AND** 其他未选中的文档不显示该图标

#### Scenario: 高亮选中文档
- **WHEN** 某个文档被选中为当前文档
- **THEN** 该文档的 expander 显示特殊的背景色或边框样式
- **AND** 视觉效果与未选中文档有明显区分

#### Scenario: 默认展开当前文档
- **WHEN** 页面加载或刷新时
- **AND** 存在当前选中的文档（`session.current_doc_id` 不为空）
- **THEN** 该文档的 expander 默认处于展开状态
- **AND** 其他文档的 expander 默认处于收起状态

### Requirement: 文档查看按钮
系统 SHALL 在文档列表的每个文档操作区域提供"查看"按钮，作为快速查看文档详情的入口。

#### Scenario: 查看按钮位置
- **WHEN** 渲染文档列表
- **THEN** 每个文档的按钮组包含 6 个按钮：查看、解析、提取、入库、清除、删除
- **AND** "查看"按钮位于最左侧（第一个按钮）
- **AND** 按钮宽度与其他按钮一致

#### Scenario: 查看按钮始终可用
- **WHEN** 文档处于任何状态（待处理、处理中、已完成、出错）
- **THEN** "查看"按钮始终可点击（不禁用）
- **AND** 点击后可以查看该文档当前已有的所有数据

#### Scenario: 查看按钮图标和文本
- **WHEN** 渲染"查看"按钮
- **THEN** 按钮显示图标 "👁️" 或 "📄"
- **AND** 按钮文本为"查看"
- **AND** 鼠标悬停时显示提示文本："查看文档详情"

### Requirement: 标签页数据联动
系统 SHALL 确保所有标签页能够正确响应当前文档的变化，自动加载和显示对应文档的数据。

#### Scenario: OCR 对比标签页联动
- **WHEN** 当前文档发生变化（`session.current_doc_id` 更新）
- **AND** 用户切换到"OCR 对比"标签页
- **THEN** 标签页自动加载当前文档的 PDF 和 Markdown 分页数据
- **AND** 如果数据不存在，显示友好的提示信息

#### Scenario: 解析预览标签页联动
- **WHEN** 当前文档发生变化
- **AND** 用户切换到"解析预览"标签页
- **THEN** 标签页自动加载当前文档的完整 Markdown 内容
- **AND** 如果数据不存在，显示友好的提示信息

#### Scenario: 提取结果标签页联动
- **WHEN** 当前文档发生变化
- **AND** 用户切换到"提取结果"标签页
- **THEN** 标签页自动加载当前文档的知识提取结果
- **AND** 显示分类统计和详细列表
- **AND** 如果数据不存在，显示友好的提示信息

#### Scenario: 知识图谱标签页联动
- **WHEN** 当前文档发生变化
- **AND** 用户切换到"知识图谱"标签页
- **THEN** 标签页显示当前知识库的完整图谱（包含所有文档）
- **AND** 如果图谱为空，显示友好的提示信息

### Requirement: 边界情况处理
系统 SHALL 正确处理文档选择过程中的各种边界情况，确保用户体验流畅。

#### Scenario: 选择未解析的文档
- **WHEN** 用户选择一个尚未解析的文档（chunk_count = 0）
- **THEN** 系统正常设置为当前文档
- **AND** 标签页显示提示信息："暂无数据，请先点击'解析'按钮"
- **AND** 不显示错误或崩溃

#### Scenario: 选择已删除的文档
- **WHEN** 当前选中的文档被删除
- **THEN** 系统自动清空 `session.current_doc_id`
- **AND** 标签页显示提示信息："暂无选中的文档"
- **AND** 文档列表中不再显示该文档

#### Scenario: 空知识库
- **WHEN** 知识库中没有任何文档
- **THEN** 文档列表显示提示信息："暂无文档，请上传 PDF"
- **AND** 标签页显示提示信息："暂无选中的文档"
- **AND** 不显示错误或崩溃
