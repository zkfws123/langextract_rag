# 变更提案：文档选择联动刷新

## Why

当前在知识库管理界面中，用户在侧边栏文档列表中选择文档后，右侧的 OCR 对比、解析预览、提取结果、知识图谱等标签页虽然已经通过 `session.current_doc_id` 实现了基础联动，但用户体验不够流畅：

1. **缺少明确的选择操作**：用户点击展开文档 expander 时，没有明确将该文档设置为"当前选中文档"
2. **缺少快速查看入口**：用户需要手动切换到各个标签页才能查看文档的详细资料，没有一键查看的快捷方式
3. **视觉反馈不明显**：当前选中的文档没有明显的视觉标识

这导致用户在管理多个文档时，不清楚当前正在查看哪个文档的资料，需要频繁切换和确认。

## What Changes

### 1. 点击 Expander 自动选中文档
- 在文档列表的 expander 中添加点击检测逻辑
- 当用户展开某个文档时，自动将 `session.current_doc_id` 设置为该文档 ID
- 右侧所有标签页（OCR、预览、提取结果、图谱）自动刷新显示该文档的数据

### 2. 添加"查看"按钮
- 在每个文档的 5 个按钮组（解析、提取、入库、清除、删除）前面增加一个"查看"按钮
- 点击"查看"按钮后：
  - 设置该文档为当前文档
  - 自动切换到"OCR 对比"标签页（或其他合适的默认标签页）
  - 加载并显示该文档的所有可用资料

### 3. 优化视觉反馈
- 当前选中的文档 expander 默认展开
- 为当前选中的文档添加视觉标识（如边框高亮、背景色变化）
- 在文档名称前显示选中状态图标（如 ✓ 或 📌）

## Impact

### 受影响的文件
- `src/ui/kb_sidebar.py` - 文档列表渲染逻辑（主要修改）
- `src/ui/session.py` - 可能需要添加文档选择相关的辅助方法
- `src/ui/tabs/ocr_tab.py` - 确保联动刷新正常
- `src/ui/tabs/preview_tab.py` - 确保联动刷新正常
- `src/ui/tabs/extractions_tab.py` - 确保联动刷新正常
- `src/ui/tabs/graph_tab.py` - 确保联动刷新正常

### 受影响的功能
- 文档列表交互体验
- 标签页数据联动
- 用户工作流效率

### 兼容性
- **无破坏性变更**：仅增强现有功能，不改变现有 API
- 向后兼容：现有的文档操作按钮（解析、提取、入库等）保持不变

## 预期收益

1. **提升用户体验**：用户可以快速选择和查看文档资料
2. **减少操作步骤**：一键查看文档详情，无需手动切换标签页
3. **增强视觉反馈**：清晰显示当前选中的文档
4. **提高工作效率**：在多文档场景下快速切换和对比
