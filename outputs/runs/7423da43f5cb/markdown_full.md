# 取用神

用神是紫微斗数金字塔最顶端的密码，神准和准之间，就差一个用神；

没有神髓，就算你四化用得再好，终究是凡流；

所谓用神，其实好像星星拟人的手法，就好像语文课上，将星星比喻成某个人，再根据命盘结构，构建出这个人的运势起伏成败；

![](images/07ca186df5600c7aa8537a589c5e7725fa0897972ab75172c4017a648fd46170.jpg)  
人无本相，却又有万相；

首先田宅宫生年巨门权，巨门星有生年四化，那么这个巨门星就被打上了身份烙印，说明家里必定存在这么一个女人；

首先这个女人必定不是妈妈，因为父母宫太阴C，太阴有身份烙印，太阴C代表妈妈，待在父母宫内，所以这个家里的女人排除掉妈妈；

同理，夫妻宫内的破军A，代表妻子，待在夫妻宫内；

那么这个巨门B，家里的女人，既不是妈妈也不是老婆，大概率就是姐妹
；

同时向心权入兄弟宫，所以命主必定有姐妹，在家里强势，有话语权，而且从事与口才相关的工作，可能是老师或者销售；

![](images/1f30fffc60c69dabe0726a7d66852276388d4d06078212895e08892cbcf5d6f9.jpg)

那么命主自己的用神是什么呢？

首先田宅的天机星是命主，贪狼忌也是命主；

因为天机星在田宅宫，就是家里的男人，天机自化禄法象妻子的用神，那么天机星和破军星就是一对；那么天机星就是自己的用神；

用神用神，以用为神，四化是一个参考，是基础象；

同理，父亲是太阳，也是贪狼；

首先太阳在父母宫，和太阴配对，那么这个太阳必定是父亲；

贪狼是时空中的父亲，太阳是物象上的父亲；比如我们要论时空的时候，太阳是静止的，没有办法论，这个时候就把贪狼当成父亲来论；

但是我们在论现象的时候，太阳是爸爸，而太阴
自化忌，就是讲的妈妈的变化，而并非是配对；

比如太阴自化忌，法象福德，一个是妈妈和外公无缘，外公容易走得早；

第二个，福德代表压力和思想，说明妈妈平时压力比较大，比较习惯管束我的兴趣爱好；

# 看婚期

已知A是妻子用神，那么大运向心A进入夫妻宫，意味着这个大运之内就和妻子结婚了；

同样的道理，取了大运夫妻宫的用神，就可以看何时和哪个女人相遇，何时分手；谁是结婚的人，又在哪一年出现；

用神就是干这个的，就好像在六亲的身上安装了一个监控；

# 第二大运：恋爱后分手

向心发射宫是短暂得到，最终落点是接收宫；

所以第二大运，大夫发射向心A到大官，只能说二运谈过恋爱，A的最终落点是大运官禄宫，而大运夫妻宫只是过一下，相当于终
点前的驿站，短暂歇脚后就会离开；

所以二运只会短暂谈一段恋爱，然后分手；

二运谈的基本上是同学，也就是在夫妻宫暂时歇脚，最终还是要离开，离开的方向是官禄，追求学业和事业；

# 第三大运：结婚

![](images/dc1c16654e5bf8995263d825c652a569c0a110fd7050015fa80cc542bfb99df0.jpg)

但是第三大运不一样，第三大运妻子的用神A，最终的目的地就是大运夫妻宫，所以这个A是奔着结婚来的；

所以这个A就是妻子，而驿站就是大运官禄宫；

以大运官禄宫作为中转驿站，那么夫妻大运辰年（流年夫妻宫走到寅宫），或者巳年（流年夫妻宫走到卯宫），就会动婚——寅宫是直接导气或者向心法，卯宫是平衡导气或者归位法；

因为大运夫妻宫得到向心禄，生年归位；

而归位的媒介和重要的点，是在甲寅；

而且甲寅宫AD，两个人的用神都齐了；
