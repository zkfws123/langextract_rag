# 二、各个星辰解说

# 一、紫微：己土

1. 主帝王星。  
2. 主有解厄制化之功。  
3.主孤。  
4. 主贵又主名、主富又主财。

紫微星疾厄症状论:

紫微星五行属己土，疾厄论主脾胃有关之疾。（症状论跟疾星辰阴阳五行有关。）

紫微星事物论:

主黄金、玛瑙、古董、高楼大厦、金融机构、银楼，如价格贵重昂贵，而本身作用力不大，但可供鉴赏如名画、古董之类。

A、主帝王星：所谓帝王有至高，无上的威严，有领袖权轮的权势，紫微星是帝王星，如古代皇帝，现代的总统，所以喜欢发号施令，也能在一瞬间，因命令的下达而使得整个情况改观。  
B、有解厄制化之功：含包容、涵盖的力量，所谓制化指紫微星对煞星有制服力，能以制服之。解厄指紫微星对凶厄之星有制化之功能，如本命大限、流年逢之，多能增加吉利，减少凶险。所谓包容，指遇到事不如意时，逢紫微星，多会表面快乐，内心痛苦，而这种内在的感应，只有当事人自己才能觉察，此不顺利的事情，紫微星多能在心情上及实质上加以化解。  
C、主孤：帝王星需要贤臣辅佐，最喜欢左辅、右弼、文昌、文曲、化科星等，同宫或三方会照，否则独坐好比孤寡君主，缺少贤臣辅佐，容易独断专行，或脾气暴躁及孤独的现象。  
D、主贵又主名：条件要落命宫、官禄宫，还要会六吉星，如左辅、右弼、文昌、文曲、化科星等。主富又主财：条件要落在命宫、财帛宫、田宅宫，还要三方会合天相、天府、化禄星等。  
E、主尊星：帝王星好比一国之尊，需要被别人所恭敬，一般紫微星坐命之人，就是需要别人的尊敬，最讨厌别人的糟蹋。

主光明(对人, 言男性; 对事, 为官禄主), 文化之传承必有太阳。对人而言, 讲亲疏关系, 它是用情意在表一切功能, 不用去管它落在什么官位, 因为它是能量而已。故所谓格物, 是指对太阳而言。日为官禄主(紫微、廉贞也是官禄主)

太阳星坐命，主光明磊落，个性慈爱，慷慨大方，不计较是非，不苟小节，豪爽之人，有正义感、公正之心，博爱之心，女命有男人之志向，工作易周旋在男性之间，女命有夺夫宿之象，如在家喜欢掌权，宜男不宜女，对金钱控制观念比较薄弱，喜欢受他人的尊重。

太阴星、太阳星都主波动之星，感情之星，主感情的波动，因此，太阳坐命之人，在儿女私情面，主感情多波动，较有感情的困扰。

# 四、武曲星：辛金

其财讲究目的论，重经营。其启发点在物曰利，在人曰爱(情威)，爱与利相交易，此为其特性。武曲不大适合在人位，在人位易有「伤」容易伤人。因为人要成长，故从武曲可以看父母的家教，反观到其家教的立场、模式。

# 武曲星事物论:

主金融机构、合作社、重工业用机械，金属类、运动员、寺塔、庙宇、高楼尖塔。

A、主将星:

主性刚强、刚硬，做事情较果决，有决断力、阿莎力、干脆型，凡事都想要快，想到就想做，但往往跟预期的目标有所差距，如欲速则不达。

B、主财星:

武曲星为紫微斗数中一颗大财星，也是颗正财星，如一分耕耘，一分收获，而较不是偏财，意外之财。财星坐命倾向有孤的现象，如愈有钱就愈孤，因太有钱之人，与人相处较会保持距离。

C、寡宿之星:

武曲星性主刚强，阳主男主刚，女主阴主柔，如刚强之星，女命坐之，再逢煞星，就比较有寡宿的现象。因此，此星宜男不宜女之星，女命晚婚为宜。

# 五、天同星：壬水

在天机的三合，主思想、信仰上的关怀。天同沟通不在知识，而在思想上的定位对否。主心灵上的(与天机白纸黑字的知识不同)。从天同亦可知人有无逻辑思维与辨正法则之概念。有时反应较慢，转不过来。思想会产生信仰，在信仰中就产生了染、净之别。
